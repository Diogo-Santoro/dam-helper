# 📚 DAM Hub — Apuntes y Recursos Colaborativos

[![Quality Gate Status](https://sonarcloud.io/api/project_badges/measure?project=Diogo-Santoro_dam-helper&metric=alert_status)](https://sonarcloud.io/summary/new_code?id=Diogo-Santoro_dam-helper)

¡Bienvenidos al repositorio central de nuestra clase de **Desarrollo de Aplicaciones Multiplataforma (DAM)**!

Este proyecto nace con una idea simple: dejar de compartir docenas de PDFs y documentos sueltos antes de cada examen y **centralizar todos nuestros apuntes, resúmenes, chuletas y simuladores de examen en un único lugar**, mantenido por y para toda la clase.

🔗 **Web en producción:** [dam-hub.vercel.app](https://dam-hub.vercel.app) _(o tu enlace de Vercel/Netlify)_

## 💻 Inicio Rápido (Desarrollo Local)

Para ejecutar la página en tu ordenador:

```bash
# 1. Clonar el repositorio
git clone https://github.com/Diogo-Santoro/dam-helper.git
cd dam-helper

# 2. Instalar dependencias
npm install

# 3. Iniciar el servidor local
npm run dev
```

Abre [http://localhost:5173](http://localhost:5173) en tu navegador para ver la web en tiempo real.

## 🛠️ Comandos del Proyecto

| Comando                | Acción                                                             |
| :--------------------- | :----------------------------------------------------------------- |
| `npm run dev`          | Inicia el entorno local de desarrollo con recarga rápida (HMR).    |
| `npm run build`        | Compila TypeScript y genera el bundle optimizado para producción.  |
| `npm run typecheck`    | Comprueba tipos en TypeScript sin generar archivos.                |
| `npm run lint`         | Ejecuta ESLint para analizar errores en el código.                 |
| `npm run lint:fix`     | Corrige automáticamente los errores reparables de ESLint.          |
| `npm run format`       | Da formato a todo el código y archivos Markdown con Prettier.      |
| `npm run format:check` | Comprueba si todos los archivos cumplen con el estilo de Prettier. |
